# Doc Styler

**Doc Styler** is a browser extension that restyles popular AI chat interfaces—including Gemini, Claude, and ChatGPT—to look and feel like Google Docs.

## Features

- Applies a clean, document-like visual style to chat interfaces.
- Supports ChatGPT (`chatgpt.com` and `chat.openai.com`).
- Supports Claude (`claude.ai`).
- Supports Google Gemini (`gemini.google.com`).

## Installation (Unpacked Extension)

To install this extension in Chrome (or Chromium-based browsers) from source:

1. Download or clone this repository to your local machine.
2. Open your browser and navigate to the extensions management page (e.g., `chrome://extensions/`).
3. Enable **Developer mode** (usually a toggle in the top right corner).
4. Click on **Load unpacked**.
5. Select the directory where you downloaded or cloned this repository.
6. The extension is now installed and active!
